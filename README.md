# Lab 3: Investigating Process Lifecycles and OS Interaction

## Overview

This laboratory explores how C programs interact with the Linux operating system. It covers process execution, process identification, exit status codes, standard input and output, and conditional execution.

## Objectives

- Understand long-running processes in Linux.
- Identify processes using PID and PPID.
- Understand program exit codes.
- Demonstrate standard input and output.
- Explore conditional execution and process termination.
- Compile and verify C programs using GCC.

## Lab Tasks

| Task | Topic | Source Code |
|---|---|---|
| Task 1 | Long-Running Process | `task1_alive.c` |
| Task 2 | Process Identity (PID and PPID) | `task2_identity.c` |
| Task 3 | Exit Codes and OS Feedback | `task3_exit.c` |
| Task 4 | Standard I/O Streams | `task4_input.c` |
| Task 5 | Conditional Execution and Termination | `task5_control.c` |
